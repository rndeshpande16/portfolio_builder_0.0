How to Create Your Portfolio

01. Pick Your Elements:

Drag elements from the sidebar directly into the editor to start building your layout.

02. Edit by section:

Click on any tab on sub-pages nav and a window will open to edit the contents of it

03. Edit till perfection:

Edit your image urls, hyperlinks and paragraph as well as heading texts. You can also add images, hyperlinks, paragraphs and headings to the existing subpage or delete it part by part or wholly!

04. Responsive view:

Resize the window from bottom right corner to view how the website looks in mobile or tablet view.

06. Customize font:

Change font by text-type. You can now use entirely different fonts for paragraphs and headings, as well as hyperlinks!

There are 8 imported fonts including Poppins, Serif, Bitcount Grid Double, Creepster, Pacifico, Ubuntu, Roboto, and Playwrite-IE

07. Change theme:

Change themes as per your vibe from the inbuilt theme templates! There are 18 of 'em only crafted for you!

08. Preview the website:

You can preview the website as it looks in reality using the preview feature by clicking on the preview icon in the side nav at the top right corner.

09. Download your website:

You can download the whole website as a zip file or also by individual pages, as per your convenience.

09. Host online through Netlify:

Directly upload your main directory to Netlify to deploy it online and share it with others

Some tips:

Check website text, links, and urls thoroughly before downloading to ensure the proper loading of the website. Even a small mistake in the url reference of an image can lead to loading of garbage images or alternative text

Use the resize option to view the mobile and tab view so that the website looks attractive across all the platforms. Also make sure to preview the website before deploying to make sure there are no errors.

Before downloading the website, make sure to change all the links in the navbars and replace it with the links of your desired website name in the domain
